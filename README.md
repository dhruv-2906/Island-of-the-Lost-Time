# 🍄 Island of the Lost Time - 3D Adventure Game

A stunning 3D adventure game featuring mushroom mountains, cascading waterfalls, and epic combat in a mystical island realm.

> **🎮 Want to play right away?** Check out **[HOW_TO_PLAY.md](HOW_TO_PLAY.md)** for simple gameplay instructions!

## 🎮 Game Overview

**Island of the Lost Time** is a third-person 3D adventure game where you explore a mysterious island filled with giant mushroom mountains, beautiful waterfalls, and corrupted guardians. Mount your trusty horse, rally your squad, and battle through five epic chapters to restore balance to the island.

### ✨ Key Features

- 🏔️ **Mushroom Mountains** - Procedurally generated giant mushroom structures that heal nearby players
- 💧 **Dynamic Waterfalls** - Realistic particle-based waterfalls with mist and splash effects
- ⚔️ **Combat System** - Engage in melee combat with various enemy types
- 🐴 **Horse Mounting** - Mount and ride your horse for faster travel
- 👥 **Squad System** - Rally AI companions to follow and assist you
- 📖 **Story Campaign** - Progress through 5 chapters with increasing difficulty
- 🌍 **3D Open World** - Explore a fully 3D environment with atmospheric effects
- 🎯 **Enemy AI** - Fight against intelligent enemies with patrol, chase, and attack behaviors

## 🎯 Story

You awaken in a mysterious land of giant mushroom mountains and cascading waterfalls. The ancient guardians of this realm have been corrupted by a dark force.

Your mission: Restore balance to the island by defeating the corrupted guardians and discovering the source of the corruption.

### Chapters

1. **Awakening in the Mushroom Forest** - Defeat corrupted mushroom guardians
2. **The Waterfall Sentinels** - Cleanse the waterfalls from sentinels
3. **The Lost Souls** - Help lost souls find peace
4. **The Corruption Source** - Journey to discover the source
5. **The Final Guardian** - Face the ultimate challenge

## 🛠️ Technical Features

### Environment System
- **MushroomMountain.cs** - Procedural mushroom generation with healing properties
- **WaterfallEffect.cs** - Particle-based waterfall with mist and splash effects
- **EnvironmentManager.cs** - Manages procedural environment generation

### Combat & AI
- **EnemyAI.cs** - Advanced enemy AI with patrol, detection, chase, and attack states
- **MeleeAttack.cs** - Sphere-based melee combat system
- **Health.cs** - Health management with damage and healing

### Game Systems
- **StoryManager.cs** - Chapter-based story progression
- **GameManager.cs** - Central game state management
- **GameUI.cs** - On-screen UI for health, controls, and story info

### Player Systems
- **PlayerController.cs** - Third-person character movement
- **CameraOrbit.cs** - Mouse-based camera control
- **HorseController.cs** - Mount/dismount system with separate movement
- **SquadAI.cs** - AI companion follow system

## 🚀 Quick Start

### Unity Setup

1. **Install Unity Hub** and **Unity 2024.3 LTS** (or newer)
2. Open Unity Hub and add the project folder: `/Prototype`
3. Install **WebGL Build Support** if you want to deploy online
4. Open the project in Unity

### Scene Setup

1. Open `Assets/Scenes/Main.unity`
2. The game will auto-initialize the following systems:
   - Environment Manager (generates mushroom mountains and waterfalls)
   - Story Manager (handles chapter progression)
   - Game Manager (coordinates all systems)

### Adding Game Elements

#### Add a Player
```csharp
1. Create an empty GameObject named "Player"
2. Add CharacterController component
3. Add PlayerController script
4. Add Health script (set maxHP to 100)
5. Add MeleeAttack script
6. Tag as "Player"
```

#### Add Enemies
```csharp
1. Create a Capsule primitive
2. Add NavMeshAgent component
3. Add EnemyAI script
4. Add Health script
5. Tag as "Enemy"
6. Set up patrol points (optional)
```

#### Add Mushroom Mountains
Mushroom mountains are auto-generated by the EnvironmentManager, or you can manually add them:
```csharp
1. Create empty GameObject
2. Add MushroomMountain script
3. Customize height, radius, and colors
```

#### Add Waterfalls
Waterfalls are auto-generated, or manually:
```csharp
1. Create empty GameObject at elevated position
2. Add WaterfallEffect script
3. Customize height and flow settings
```

## 🌐 WebGL Deployment

The project includes GitHub Actions for automatic WebGL builds:

1. Push to the `main` branch
2. GitHub Actions will build WebGL version
3. Deploys to GitHub Pages automatically
4. Play online at: `https://yourusername.github.io/Island-of-the-Lost-Time/`

### Manual Build

1. File → Build Settings
2. Select WebGL platform
3. Click "Switch Platform"
4. Click "Build And Run"
5. Choose output folder
6. Wait for build to complete

## 🐛 Troubleshooting

### Common Issues

**Player can't move:**
- Ensure CharacterController is attached
- Check that ground layer is walkable

**Enemies don't attack:**
- Verify NavMesh is baked in scene
- Check enemy detection range
- Ensure player is tagged "Player"

**Mushroom mountains don't appear:**
- Check EnvironmentManager is in scene
- Verify autoGenerate is enabled
- Check generation radius settings

**Waterfalls have no effect:**
- Ensure ParticleSystem component exists
- Check particle limits in Quality Settings
- Verify render pipeline supports particles
